# Política de Privacidade — Automação Como Jesus Cristo faria?

Esta automação é de uso próprio do responsável pelo canal **Como Jesus Cristo
faria?** e utiliza a API do YouTube exclusivamente para publicar vídeos no
canal autorizado pelo próprio responsável.

## Dados acessados

A aplicação solicita apenas a autorização necessária para enviar vídeos ao
YouTube. Ela não coleta, vende nem compartilha dados pessoais de terceiros.

## Armazenamento e segurança

As credenciais OAuth são armazenadas como segredos criptografados do GitHub
Actions e não são gravadas no código-fonte público. O acesso pode ser revogado
a qualquer momento nas configurações de segurança da Conta Google.
